# EPFL MATH-454 — Parallel and High-Performance Computing

## Scope and public material

EPFL's official coursebook describes a four-credit course covering modern HPC architectures, benchmarking, multicore systems, scaling, OpenMP, MPI, hybrid programming, GPUs, and profiling.

## What it contributes

The course's distinctive contribution is architecture selection: students learn to identify which machine style fits an algorithm instead of applying one platform universally. This supports a decision gate before code-level tuning.

## Transfer to trading systems

The skill should classify whether a workload is per-event latency, batched throughput, shared-memory parallel, distributed, or accelerator-friendly before choosing tools. It should include profiling and scaling evidence and explicitly model transfer or communication costs.

## Limits

Only the official coursebook summary was used; public assignments and detailed lectures were not identified. It supports the architecture-selection principle but not detailed implementation instructions.
